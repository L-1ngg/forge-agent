# ADR-020: 当前文档与历史归档分离

> 状态:已批准(2026-09-21，operator 确认归档方案并要求一次性完成)。补充 ADR-001 的文档生命周期与读取入口，其余职责分工保留。

## 背景

已被替代的内核、SDK、上下文策略与早期阶段材料仍和当前施工图混放，文档导航甚至将旧策略列为现行入口；Skills 已交付而 plan 与施工图仍显示待实现。仅靠文件年代或正文里的历史说明，不能可靠区分当前合同和历史证据。

operator 提出归档已不再需要默认读取的文件，并在审阅“归档、入口收敛、状态校正”方案后要求：“请你直接一次性帮我处理好所有的”。

## 决策

- `docs/README.md` 导航当前契约与验收依据；`docs/plan.md` 维护当前行动项。按任务进入对应文档，不默认遍历全部历史材料。
- 已被替代的施工图、已中止路线和完成选型使命的研究迁入 `docs/archive/`，保留原有类别与文件名；归档继续由 Git 管理。归档不表示验收通过，也不产生新的实施授权。
- 仍适用的合同和必要证据留在现行目录；混合文档先将仍生效的约束和未测边界放入当前权威入口，再归档。实验原始数据不因目录整理而改写。
- ADR 保留编号和路径，通过状态及替代指针解释效力。初次历史决策正文保留；当前实现入口指向现行合同。
- `.ignore` 排除 `/docs/archive/`，让默认 ripgrep 搜索和文件枚举跳过归档；追溯时显式使用 `rg --no-ignore ... docs/archive` 或按路径读取。它不是访问控制，也不影响 Git 跟踪。
- 跨会话 `review-notes/` 按 operator 同日要求仅在本地保存，由 `.gitignore` 排除；项目契约与可共享证据继续写在版本化文档中。

具体归档条件、读取方式与维护步骤统一见 [文档规范](../README.md#归档与读取规则)。历史文件索引与当前替代入口见 [归档索引](../archive/README.md)。

## 取舍

| 方案 | 判断 |
|---|---|
| 保持目录混放，只增加历史标记 | 旧正文仍进入默认搜索，现行导航容易持续引用过时依据 |
| 按年龄或已完成状态批量归档 | 会移走仍有效的合同和必要验收边界 |
| 将历史文档全部从 Git 移除 | 项目证据和决策来源失去共享入口；仅本地交接适用 |
| 按适用性归档，并整理入口与搜索范围 | 采用；增加搬迁时修复引用的工作，减少日常读取的歧义 |
