# ADR-019: Markdown 持久记忆与 worktree 独立副本

> 状态:已批准(2026-09-17；存储与 worktree 设计仍适用，会话内调度及写保护协议于 2026-09-28 被 [ADR-026](026-native-skills-and-markdown-memory.md) 取代)。以下旧实现细节仅供追溯。

会话历史保存原始记录，工作记忆沿用上下文压缩检查点，长期记忆使用可手写的 Markdown 主题和模型维护的短索引。笔记的未来用途、限定和冲突由当前模型判断；程序保障作用域、文本资源、旧写保护和明确提交结果。来源用于回查，不能证明语义或扩大权限。保留 ADR-017 的工作记忆证据合同，不要求长期笔记复制其 schema。

CLI 在用户数据目录维护记忆，主 worktree 维护仓库主记忆。其他 worktree 首次使用时复制当时的 Markdown，随后独立修改；选择副本而非共享目录是为避免分支经验互相覆盖。初始化不复制用户通用偏好、会话或操作状态，不与 Git 分支合并绑定。

SDK 由宿主显式绑定目录与 scope，不配置即无记忆副作用。统一装配和预算位于会话层；runtime 保持通用。会话内受管理工具完成更新，不引入后台计时器、数据库、候选审批或退出整理调用。文件编辑采用乐观版本核对与单文件原子替换，不承诺跨文件事务或任意外部编辑器无冲突合并。旧接口、预算及验收见[历史施工图](../archive/phases/persistent-memory.md)；当前合同见 [ADR-026](026-native-skills-and-markdown-memory.md)。
