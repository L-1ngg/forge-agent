# ADR-009: 自研 Agent 执行内核

> 状态:已批准并进入施工(2026-09-05)。operator 已要求按规划实现,施工与验证记录见 [自研执行内核](../phases/owned-core.md)。

## 背景

operator 在通用 Agent 定位上追加“agent 核心自研”。该决策取代 [ADR-008](008-general-agent-positioning.md) 决策 2 中继续使用 pi `Agent`、不重写 loop 的部分,其余单 Agent 与分层复用边界不变。

当前执行循环、工具调度和 steering/follow-up 由 `pi-agent-core` 的 `Agent` 承担;自有代码负责会话持久化、权限总线、工具、事件适配和 TUI。自研必须真正接管执行职责,不能只是再包装 `Agent` 或改用 pi `agentLoop()`。

## 决策

1. **自研执行内核:**自行实现模型与工具之间的循环、继续/终止条件、执行状态、消息上下文、事件输出和 usage 更新时机。
2. **自有调度:**接管工具入参校验、执行调度、结果收集、错误处理、取消、steering、follow-up 与实例级队列生命周期。对接现有权限机制,确保授权对象与实际执行入参一致。
3. **保留模型层:**继续依赖 `pi-ai` 处理模型调用、认证、供应商协议与流解析。供应商类型留在模型适配边界,不扩散到公共 SDK 或 TUI。
4. **首版保持能力:**以已有行为契约为基线,不同时引入新的 Run/Step 模型、执行预算或检查点恢复。会话存储、权限规则、请求总线、工具和 TUI 不因替换内核而重写。
5. **先内核后 SDK:**内核替换通过验收后,再完善宿主装配与公开 SDK;避免先发布绑定旧核心的接口。
6. **不扩边界:**Team 编排与内置子 Agent 编排仍不进入当前路线,TUI 美化继续暂缓。技术栈与五包结构不变。

## 迁移与回退

先提炼现有可观察行为契约,再实现自研内核并切换 CLI/TUI。迁移期允许旧实现作为测试对照;完成后移除 `pi-agent-core` 的直接依赖与生产调用,不长期维护双引擎或永久兼容开关。以独立提交提供回退点,具体批次在施工图确定。

保留现有 CLI、事件和会话行为,包括 provider continuation 信息、取消不落盘半个执行、工具调用与结果配对。SDK 公共接口在后续阶段确定,本轮不新增类型或冻结内部实现符号。

`pi-ai` 的 Responses 终态补丁继续保留:移除 `pi-agent-core` 不是移除该补丁的理由。上游修复后才能在对应回归通过的前提下另行移除。

## 被否方案与成本

| 方案 | 不采用的原因 |
|---|---|
| 包装 pi Agent 或改用 agentLoop | 循环与关键状态仍由上游拥有,不满足自研目标 |
| 同时自研供应商适配 | 扩大认证、流协议和兼容性维护面,不属于本次选择 |
| 首版同时重设运行模型与检查点 | 无法区分替换回归与新语义变化,验收面过大 |
| 永久双引擎 | 长期承担两套执行语义与测试维护成本 |

自研意味着本项目自行承担调度、取消、异常收尾和事件一致性的维护责任;不能以代码可编译或单次问候成功作为替换验收。现有回归是起点,不是完整规格。

## 后续施工验收

以下是后续实现的出口要求,不是本轮已通过项:

- [ ] AC-CORE-01:文本流、连续工具调用、并行工具中单项失败和现有各类 stop reason 保持正确语义。
- [ ] AC-CORE-02:改写后的权限检查、拒绝执行、阻塞交互和取消均走自研生产路径。
- [ ] AC-CORE-03:streaming/工具执行期间取消、提前关闭迭代器、并发运行拒绝和实例复用均正确收尾。
- [ ] AC-CORE-04:steering/follow-up 时点、顺序、持久化及取消后队列清理符合锁定契约。
- [ ] AC-CORE-05:工具调用与结果配对;取消不落盘半个执行;会话重开保留 provider signature。
- [ ] AC-CORE-06:CLI JSON 退出码、TUI/PTY 交互和 usage 无回归;多个实例状态互不串扰。
- [ ] AC-CORE-07:迁移既有契约测试到自研内核,结合属性测试、故障注入、本地 HTTP 和受控真实 provider 请求验证;不能继续调用旧执行器来证明新内核正确。
- [ ] AC-CORE-08:移除 pi-agent-core 直接依赖和生产调用,保留 pi-ai 及必要补丁;依赖检查、typecheck 和完整测试通过。

SDK 发布前另行验收宿主接入契约。各批记录 Ran / Not run / Why / Risk,明确未测边界。
