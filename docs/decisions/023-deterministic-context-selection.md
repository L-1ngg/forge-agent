# ADR-023: 上下文压缩使用确定性的近期历史选择

> 状态:已批准(2026-09-26)。operator 在讨论压缩复杂度后同意简化选择规则并要求实施；施工与验收见[施工图](../phases/context-selection-simplification.md)。
> 参与者:operator、Codex。

## 背景

[ADR-017](017-evidence-backed-context-compaction.md) 的材料选择同时使用状态来源、词项相关性、时间和重复正文判定。短检查点与历史搜索交付后，当前投影尚无独立的真实模型质量评估；首次对照实验也不能单独证明这些选择启发式的收益。多种启发式组合使压缩后的上下文难以预测和排查。

## 决策

本决策仅替代 ADR-017 第 3 节中可选材料的相关性排序与去重规则，不改变任务状态检查点、持久化格式、工具权限或预算恢复合同。

1. 保留未归档用户输入、最新用户消息和最后一个完整交互单元。旧的可找回工具正文仍可在请求投影中裁剪；工具调用与结果作为完整交互单元保留或移出。
2. 若仅裁剪旧工具正文就能让全部历史符合请求预算并缩小投影，保留全部交互单元。否则从最新单元向前扫描；在 `keepRecentTokens` 的可选材料额度和请求输入预算内连续保留。遇到首个放不下的单元即停止，不跳过它去挑选更旧的单元。
3. 不再依据检查点来源、任务词项或内容重复性选择可选原文。被移出的未归档材料仍须先进入带来源的检查点；已保存原文继续可经 `search_context` 和 `read_context` 找回。

## 取舍与证据边界

选择结果更容易解释，且不再需要词项提取、评分与去重身份规则。旧来源可能不再作为完整消息直接出现在下一请求中，模型需要依靠短检查点和按需找回。首次真实模型对照属于旧选择实现，不证明此变更后的质量、费用或延迟；软件合同验证与新的真实模型评估必须分开报告。

持久化检查点字段与公开配置不变，既有会话无需迁移。若新策略的任务质量不能接受，可恢复旧版本代码读取同一会话数据；不得将这视为已有真实模型回退验证。
