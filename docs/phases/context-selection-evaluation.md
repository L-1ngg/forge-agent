# 近期历史选择的模型质量评估

> 状态:已完成(2026-09-26)。本实验只评估 [ADR-023](../decisions/023-deterministic-context-selection.md) 的材料选择变更；软件合同见[施工与验收](context-selection-simplification.md)，原始数据与复现命令见[实验记录](../research/context-selection/README.md)。

## Entry / Design

operator 已确认用新冻结任务集比较简化前后的选择规则。A 为实施前提交 `62c7f2574126ad713f30811b74a2abbbccab290b` 的旧选择实现，B 为本次近期连续选择实现；运行时除 `packages/core/src/context/compact.ts` 外须一致。分别记录实现文件 hash、runner/fixture hash、配置及 provider 实际返回模型。旧 `context-tasks-v2.json` 已用于先前设计，仅作历史依据。

八类任务各有一个开发样本和一个独立保留样本：远期有效约束、近期纠正、超大中间单元、精确原文证据、重复记录、连续压缩与任务切换、已记录副作用、只裁剪工具正文的对照。开发样本用于连通性、费用与评分调试；保留样本的历史、答案、评分和运行配置在首个保留集模型请求前冻结。每个保留样本在 A/B 各运行三次，共 48 次。两版使用相同模型、系统提示、历史、工具、权限、窗口、输出上限、重试与压缩配置，并行启动且按同一任务顺序运行，记录每次请求耗时；这不能消除 provider 负载差异。

付费运行前通过公开 SDK 和本地受控 HTTP 模型完成投影预检：前七类应有预期的 `keptIds` 差异，对照场景两版应相同；未形成差异的样本不能回答本次问题。精确证据值不能出现在任务提示或短检查点，评分要求成功读取含目标值的原文。副作用工具只计数，不执行真实操作。

## 预注册评分与出口

- [x] AC-1: 新 fixture、runner、汇总器固定样本及其 SHA-256；汇总器独立重算评分并拒绝缺失、重复、混合配置/源码或伪造评分。
- [x] AC-2: 所有保留集运行均计入结果，包括失败、超时和无 usage 的调用；总 Token 仅在该次所有调用均有 usage 时报告，否则显式计为未知。费用包含任务、摘要、失败与检索后续请求。
- [x] AC-3: 逐次校验产物字段、最新决定、旧约束、来源和额外副作用。B 不允许额外副作用；在远期约束、纠正、精确证据及任务切换四类中，B 的三次运行均须完成且通过全部硬约束。B 总完成数不得低于 A；A 某类若 3/3 完成，B 不得低于 3/3。
- [x] AC-4: 报告任务完成、各硬约束、精确证据读取、检索次数、任务与摘要请求数、总 Token、估计费用、总耗时与压缩耗时。费用和延迟是取舍指标，不假设简化必然降低它们。

受控投影预检通过后，开发样本 A/B 各一次；再运行保留集。每个进程有请求与保守费用上限，A/B 合计预留上限 USD 8，开发样本另限 USD 2；实际账单以供应商为准。保留集出现质量失败时保留原始记录，不修补样本后重跑并称为独立验收。若改实现，另冻一套新保留集。

## 结果

首轮 v1 保留集两版均为 21/24，唯一失败是精确证据样本两版各三次在模型请求前触发 `summary_input_budget_exceeded`。原始记录、失败报告和当时的 runner/report 源码快照均保留；这是夹具预检未计入 SDK 固定提示/工具预算的缺陷，不作为模型质量结论。随后修正为公开 SDK + 本地受控 HTTP 预检，并以新数据冻结 v2；没有修改 v1 结果或沿用其保留样本。

v2 保留集使用 xai / `grok-4.6`，实际返回 `grok-4.6`；声明窗口 32000，`maxTokens` 2048、`reserveTokens` 10000、`keepRecentTokens` 900、thinking off、retry 0。A 使用 HEAD `62c7f2574126ad713f30811b74a2abbbccab290b`，B 使用本次工作区实现；汇总器核对的其他六个运行时文件内容相同。八类样本的预检均成立，评分门槛通过。

| 指标 | A 旧选择 | B 近期连续选择 |
|---|---:|---:|
| 任务完成 / 全部硬约束通过 | 24 / 24 | 24 / 24 |
| 额外副作用 | 0 | 0 |
| 精确证据完成且读到目标片段 | 3 / 3 | 3 / 3 |
| 原文读取成功 / 请求 | 4 / 4 | 18 / 18 |
| 全部模型请求 / 摘要请求 | 76 / 31 | 82 / 32 |
| 总 Token | 574539 | 574251 |
| 目录费率估计费用 USD | 1.258966 | 1.258538 |
| 任务耗时中位数 / p95 秒 | 36.95 / 129.04 | 29.98 / 131.00 |
| 压缩耗时中位数 / p95 秒 | 24.44 / 117.18 | 22.06 / 121.41 |

全部 158 次模型请求都有 usage；Token 和费用包含摘要、任务、失败与检索后的请求。B 多 14 次原文读取和 6 次模型请求，Token 少 288、估计费用少 USD 0.000428，差额远小于这个小样本和并行 provider 调度的波动，不支持“更省钱”或“更快”的结论。两版产物完成率相同；B 的状态/证据主要由短检查点与原文读取支撑。对照场景也出现一次 B 的主动读取，因此不能把每次读取差异都归因于投影规则。

## 验证与边界

Ran：v1/v2 开发与保留集、完整 SDK 预检、独立报告复算；篡改完成评分和删除样本的反向验证均按预期拒绝。`bun run check`、`bun run typecheck:examples`、`git diff --check` 与本次六份文档的本地链接目标检查通过；v2 的 runner/report/候选源码快照 SHA-256 与运行版本一致。模型调用累计目录费率估计 USD 6.262540，含连接探针、v1 失败实验、两轮开发和 v2 正式保留集；分项见[实验记录](../research/context-selection/README.md)。

Not run：其他 provider、真实长任务、人类语义审阅、物理窗口超限与不同操作系统的真实模型运行。Why：本次验证聚焦单一模型、固定构造历史与简化前后材料选择。Risk：8 类 × 3 次不能证明一般语义等价；任务完成评分只覆盖预设字段和副作用，检查点可能遗漏未入题的需求；单 provider 并行时延不可当作隔离性能基准。真实部署副作用未执行。
