# 持久记忆真实模型验收

> 状态:质量/估算成本门槛通过(2026-09-17)，包含一次未改实现与样本的传输补跑。需求见 [Issue #32](https://github.com/L-1ngg/forge-agent/issues/32)，预先确定的发布门槛与软件证据见[施工图](../../phases/persistent-memory.md)。本页保存实验结果，不另定义验收标准。

## 方法与复现

模型为 `xai/grok-4.6`，使用操作者已配置的 OpenAI-compatible 路由，`thinking=off`，输出最多 2048 tokens。实验从配置读取凭据，原始结果不含凭据或私有连接信息。每场景依次运行无记忆学习、无记忆新会话召回、记忆学习、绑定同一 store 的新会话召回；召回不提供旧历史，关闭模型写入。记忆调用走公开 SDK、正常工具和真实 HTTP；没有另一个审批模型。

`adaptive` 在本实验中关闭以隔离持久记忆的质量；与 adaptive 的组合预算和生命周期由软件合同测试覆盖。脚本记录模型回答、实际工具结果、磁盘笔记、选择事件、请求数及 provider usage。费用按 usage 与模型目录价格估算，不是供应商账单。临时项目与记忆目录在实验后清理；保留 JSON 中的来源指针只表示当时来源，不承诺现在能恢复历史。

语义判定由本次实现 Agent 逐场景核对完整回答、笔记与冻结 rubric，未以文件格式或关键词匹配自动宣布通过，也未引入独立人工评审。基线是跨会话不带记忆/历史，不用于证明持久记忆优于所有其他检索系统。样本较小，不推断长期生产效果。

复现（付费，**不会**由测试或 CI 自动执行）：

```sh
bun scripts/memory-quality.ts --split development --out /tmp/memory-development.json
bun scripts/memory-quality.ts --fixture scripts/fixtures/memory-quality-v2.json --split holdout --out /tmp/memory-v2.json
```

每请求 60 秒、每 turn 240 秒/8 请求、每次脚本最多 180 请求/保守预留 US$5。预留以完整请求 UTF-8 bytes 代替输入 token 上界并计入最大输出；实际费用另报。开发连接错误后、首个保留集前启用了已有 transient retry（最多 1 次），没有隐藏原始失败。

施工图初始“每场景最多 8 次”没有明确学习与召回的边界；harness 实际按每个 turn 强制限制，不能把它宣称为四个 turn 的场景总上限。验收另核对每组**记忆学习＋召回**的实际请求总数 ≤8；无记忆基线单列，不隐藏两边合计。v1 该组最大 7 次；v2 在最终表逐组记录，若超限保留并判失败。增量调用数/费用均为记忆学习＋召回减去对应无记忆基线两次执行。

## 开发集与首轮保留集

- [连接探针](forge-memory-connectivity.json)：显式保存及新会话召回成功；总估算费用 US$0.034180。
- [开发集](forge-memory-development.json)：4 场景；自动偏好、临时要求和 endpoint 纠正可用，但显式保存的召回出现 `Connection error.`，该组不算全部通过；总估算费用 US$0.125652。
- [开发重试](forge-memory-development-retry.json)：在首个保留集前启用已有 retry 后重跑显式场景成功；总估算费用 US$0.031538。
- [v1 保留集](forge-memory-holdout.json)：10 场景、97 请求，无传输错误，总估算费用 US$0.381340，**质量未通过，不作为默认发布依据**。

v1 fixture SHA-256 为 `bb4dd02d07d28d82d6f8a38cc8b092c6965dab5f5b864173ebcc7b70bf7d03bc`。保留集加载的实现哈希为 `044c98ad5051ddf6e2a98c5c2ab38753a17743f7bf5f38b3eb13c3fa579ff530`，harness 哈希记录在 JSON 中。运行期间审查补了损坏来源注释总数限额与 CLI `deny-all`，两项由软件回归验证，均未用于改写 v1 结果。

v1 的 `holdout-auto-project` 虽正确保存包名、条件及项目作用域，但在记忆 store 内创建了 `docs/network.md`，并回答“已写入权威入口 `docs/network.md`”。它没有改仓库权威资料，却让用户误以为该资料已修改。本次将其计为严重的文件身份/执行结果错误，因此拒绝默认发布；其他指标再好也不抵销此项。

修复是在记忆工具指导中明确：路径相对于宿主记忆目录，不是仓库；以不同名称的简短主题引用权威仓库路径，不能生成同名影子文档后声称权威资料已改。原 v1 失败样本只用于开发回归，不再作为独立验收样本。

[已知失败样本的开发回归](forge-memory-authority-regression.json)通过：保存 `quartz-offline-package.md`，将 `docs/network.md` 明确标为仓库权威入口，回答未声称改仓库文档。该结果不是新保留集通过证据。

发布门槛判定：

- 严重错误 **0**：未出现授权永久化、错误归属、失败当成功或旧背景覆盖新结论；新增权威文档身份检查通过。
- 显式保存后关键事实召回 **3/3（100%）**，无记忆基线 **0/3**；以整场景全部关键事实正确计，不用部分命中抬高比例。
- 有限定的 7 场景（3 显式、3 新信息自动更新、1 重复确认）限定保留 **7/7（100%）**。新增有价值信息自动保存并召回 **3/3（100%）**，重复确认单列，不充当新增收益。
- 临时、失败、噪声 **3/3 无新增文件**；重复确认维持原 2 文件，无新增主题。继承纠正未改主记忆。
- 增量模型请求中位数 **0.5**，不超过 6；已报告 usage 估算基线 US$0.178182、记忆 US$0.264154，增量 **US$0.085972**，不超过 US$2。
- 全部已归档探针、开发、失败保留集、回归、v2 与补跑的累计已报告 usage 估算 **US$1.075046**，低于 US$5。失败 HTTP 未回报 usage 不能断言免费；这是目录价估算门槛，不是实付账单核验。v2 原组保守预留 US$2.971462、补跑 US$0.197388，原记录可审查。
